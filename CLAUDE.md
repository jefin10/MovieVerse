# MovieVerse

Monorepo: `MovieVerseApp/` (Expo React Native app), `movieverse-website/` (Next.js site), `MovieVerse-Backend/` (Express + Prisma API), `MovieverseAI/` (Flask mood and recommendation service).

## UI rules

- **No subtitles, anywhere.** A screen, section, card or row gets a title and nothing under it: no supporting sentence, tagline or description line. This applies to the app, the website and anything new. If something needs explaining, the title or the control itself should carry it.
